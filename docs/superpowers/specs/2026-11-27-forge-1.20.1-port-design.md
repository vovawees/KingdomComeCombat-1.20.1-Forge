# Kingdom Come Combat → 1.20.1 Forge ONLY — Design

Date: 2026-11-27
Status: Approved by user ("Делай"), variant 1 chosen.

## Intent / why
Port **Kingdom Come Combat** (`kingdom_come_combat`, currently MC 1.21.7 Fabric + NeoForge 1.21.1 + half-standalone
`forge-1.20.1` shim over a 14-version Fabric multi-build) to a **single standalone Minecraft 1.20.1 Forge mod**.
Reasons from user: target only their FreeSM 1.20.1 pack; no other versions/loaders; minimum dependencies; no
reduction of realism (can add); already-good textures (e.g. mob_effect/particles) must stay; finish the crosshair;
add broad mod compatibility; optimize.

## Goals
1. **Target:** Minecraft **1.20.1**, **Forge 47.4.0**, Java 17. No Fabric/NeoForge/other-MC-version outputs.
2. **Standalone:** one Gradle project; no cross-building from a Fabric root; modid `kingdom_come_combat` unchanged;
   existing datapack/`kingdom_come_combat` JSON API unchanged.
3. **Vanilla + realistic art (never reduce realism):** textures → vanilla-style **16×16** (keep detail; don't strip
   existing good art; normalize oversized items; clean alpha; vanilla palette; add shading where flat); keep good
   mob_effect/particle/effect textures; **finish/upgrade crosshair** set (`cross_base/up/down/left/right/without_up`,
   `hardcore_lock_point`, `direction_block`, lock-on). Animations (PlayerAnimationLib, `format_version 1.8.0`) →
   smoother realistic motion, reduce jitter, proper anticipation/weight/follow-through, sane easing, normalized
   timing; **preserve exact bone names + hit/block event windows**; don't reduce realism.
4. **Mod compatibility, no hard deps:** `KccModCompat` optional-integration layer; cached `ModList.isLoaded`;
   soft degradation; optional `compileOnly`; keep existing FirstPerson/YesSteveModel/EMF hooks; honor
   `required_mods`; don't shadow/break others' mixins; target pack mods incl. **TACZ, Curios, GoProne,
   NotEnoughAnimations, Quark, SereneSeasons, Immersive Vehicles, KubeJS**.
5. **Minimum dependencies:** required runtime = MC Forge + (one bridge: Sinytra **Forgified Fabric API** iff needed
   after audit) + **PlayerAnimationLib** + **GeckoLib** only where already used; **drop hard `cloth-config`**
   (config screen optional); no bundled extra jars; optional integrations `compileOnly`.
6. **Optimization:** no per-tick allocation churn; cached compat booleans + `ModList`; cheap HUD; 16px textures
   (smaller atlas); sound pooling; `isLoaded` short-circuit; safe mixin `require`/`cancellable` minimal; don't
   fight `modernfix`/`radium`/`starlight`; no reduced behavior, just efficient.
7. **No realism loss; keep all gameplay.**

## Non-goals / anti-goals
- No multi-version output, no Fabric/NeoForge artifacts, no other MC versions. 
- No pulling extra third-party libraries. No hard dependency on any other mod. No GitHub Actions/CI.
- Not reducing realism or removing existing good textures/animations; not changing combat balance as part of this port
  unless required for 1.20.1 API. Not rewriting the 61k-LOC gameplay from scratch.

## Constraints
- MC 1.20.1 mappings (official/Forge SRG via existing pipeline; currently Yarn on Fabric + generated `versionCompat`).
  Reuse existing effective 1.20.1 source set (`src` + `compat/1201` + `compat/legacy` + generated 1.20.1 variants +
  `LegacyForgeDamageSources` + PAL source-backport `compat/1201`), don't hand-rewrite.
- Java 17. Forge `@Mod`, `net.minecraftforge` events, Mixin. Keep modid + packaging `com.kingdomcomecombat`.
- Git: user's global rules (commit+push per stage; **no `.github/workflows`**; `.ai/`; good README; no secrets in output).

## Approaches considered
- **A. Clean standalone Forge-1.20.1-only project (CHOSEN).** Flatten `forge-1.20.1` to root; lock `target_mc=1.20.1`;
  keep shared sources; remove other loaders/versions; minimize deps; keep behavior. Lowest risk, meets "only".
- **B. Keep multi-version Fabric root, disable others.** Rejected: doesn't meet "only"; dep bloat.
- **C. Pure-Forge rewrite dropping Forgified Fabric API.** Rejected for scope: 35 Fabric APIs to re-bridge;
  contradicts minimum-change; can revisit later if user wants zero-FFAPI. (Dependency audit at build time decides
  whether FFAPI can be dropped; goal is minimum, not zero.)
- **D. Full rewrite.** Rejected.
