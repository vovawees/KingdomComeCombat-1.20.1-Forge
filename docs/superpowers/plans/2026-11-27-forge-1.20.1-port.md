# Kingdom Come Combat → 1.20.1 Forge ONLY Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Kingdom Come Combat into a single standalone Minecraft 1.20.1 Forge mod (modid `kingdom_come_combat`)
with vanilla-style realistic textures/animations (never reduced realism), broad optional mod compatibility, minimum
dependencies, and optimization — no other loaders/versions.

**Architecture:** One Gradle Forge-1.20.1 project. Reuse the existing effective 1.20.1 source set
(`src` + `compat/1201` + `compat/legacy` + generated `versionCompat` + `LegacyForgeDamageSources` + PAL source
backport), flattened from `forge-1.20.1`, `target_mc` locked to `1.20.1`. Remove Fabric/NeoForge/1.21.x machinery.
Add `KccModCompat`. Restyle assets in-place. Keep datapack API.

**Tech Stack:** Minecraft 1.20.1, Forge 47.4.0, Java 17, Mixin + MixinExtras, PlayerAnimationLib, GeckoLib (existing
use), Sinytra Forgified Fabric API **iff still required after audit**, Gradle (wrapper 9.4.1). No CI. No new deps.

**Spec:** `docs/superpowers/specs/2026-11-27-forge-1.20.1-port-design.md`

## Global Constraints
- MC **1.20.1**, Forge **47.4.0**, Java **17**. modid `kingdom_come_combat`. Package `com.kingdomcomecombat`. Version preserved.
- **Only** 1.20.1 Forge output; no Fabric/NeoForge/other-MC-version artifacts; no `target_mc` matrix.
- **No new dependencies; no bundled jars; optional integrations `compileOnly`; no hard dependency on any other mod; drop hard `cloth-config`.**
- **No realism reduction; can add.** Keep existing good textures (esp. `mob_effect`, `particle`, `gui`); keep PAL bone names + hit/block windows.
- **No `.github/workflows`; no CI. No secrets in output. Commit+push per stage.** `.ai/`. 
- Keep existing `kingdom_come_combat` datapack format + `required_mods`. Keep all gameplay; only 1.20.1 API adaptations.
- User language Russian for chat; code/identifiers English; match existing style.

## Review Focus (failure modes with no direct test; verify manually in smoke run)
1. **Modlist size ~100 pack mods** — nothing KCC does may crash when TACZ/Curios/GoProne/NotEnoughAnimations/Quark/KubeJS/ImmersiveVehicles present; optional hooks guard with `isLoaded`.
2. **No PlayerAnimationLib/FFAPI at runtime** in a clean pack — clear error vs silent broken animations (document required runtime).
3. **GeckoLib absent** — `@Mixin(targets="software.bernie.geckolib...", remap=false)` must not crash without GeckoLib (`require=0`); rendering must degrade.
4. **Server (dedicated) run** — client-only classes never loaded server-side; `DistExecutor`; no client mixin applied on server.
5. **Texture slot integrity** — every restyled PNG stays same path + correct dimensions; no broken model/mcmeta; alpha preserved; crosshair not clipped.
